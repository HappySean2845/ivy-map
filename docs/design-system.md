# 设计系统 · 野兽派编辑风

> 参考 [`ui-design.md`](ui-design.md)（Wemakethings：brutalist editorial broadsheet）。
> **本文是约束，不是灵感板。** 组件实现有冲突以本文为准。

---

## 0. 为什么这个方向对，以及一处必须偏离

参考站的判断标准是一句话：**类型是唯一的建筑材料。** 纯黑纯白、零彩色、零圆角、零阴影、hairline 分隔、巨型字做骨架。

这个方向对我们特别合适，理由不是审美：

1. **主用户会截图发家长群。** 纯黑白在截图、转发压缩、黑白打印、色弱视觉下**全部无损**。彩色强调一旦被压缩或截半就废了。
2. **零彩色 = 零暗示。** 这个产品的立场是「我们只摆数据，不煽动」。用颜色引导注意力，本身就是一种煽动。
3. **hairline + 巨型字**天生是报刊排版语言，和「研究报告」而非「App」的定位完全一致。

### 一处必须偏离：表格区不降低信息密度

参考站是**作品集站**——低信息密度、慢节奏、长滚动，一屏一个概念。
我们是**数据工具**——家长要在一屏内横向比较 7 所学校的 6 个维度。

**所以：区块之间用参考站的大留白（80–120px），表格内部保持紧凑。**

硬套「低密度」会让家长为了对比两所学校反复上下滚动——那不是克制，是失职。留白花在**区块之间**，不花在**行与行之间**。

### 第二处偏离：中文没有大写

参考站的层级几乎全靠 `all-caps` 建立。中文没有这个概念。
替代方案：**拉丁文部分保持全大写**（`IVY MAP`、`A-LEVEL`、`L1`），中文用**字号跨度 + 字距 + hairline** 建立层级。

## 1. 色彩：只有两个值

```css
--ink:   #000000;   /* 文字、所有边框、描边、下划线 */
--paper: #ffffff;   /* 画布、卡片、填充按钮底 */
```

**没有第三个颜色。** 没有灰阶变量、没有强调色、没有信号色、没有深色模式。

> **`/v2` 有一处受限的例外。** 刷卡界面里每所大学用自己的校色做身份锚点（卡片顶部
> 3px 色带、monogram 方块底、雷达图填充、右划反馈四处，仅此四处）。
> 边界、理由和禁止项见 [`design-system-v2.md`](design-system-v2.md)。
> **现有 `/` 榜单不受影响，仍然是纯黑白。**

层级靠 **opacity** 而不是新颜色：

| 用途 | 做法 |
|---|---|
| 次要文字 | `text-ink/60` |
| 更弱的注释、占位、「—」 | `text-ink/40` |
| hairline 分隔线 | `border-ink/15` |
| 表头下的粗线 | `border-ink`（1px 实色） |
| 当前选中 | **反白**（`bg-ink text-paper`），不是换颜色 |
| 需要注意（分母缺失、不可申请、估算） | **不用颜色**，用 `text-ink/40` + 文字说明本身 |

> **「用红色标警示」这条被删掉了。** 上一版用朱红做信号色，现在没有色可用了——
> 而这反而更好：警示由**文字内容**承担（「分母缺失」「仅招收外籍」），
> 不由颜色承担。截图后、色弱、黑白打印下，文字永远还在，颜色不一定。

**取消深色模式。** 参考站只有 light。黑白系统本来也不需要深色变体，删掉省下 177 个 `dark:` 变体和一整套维护成本。

### 数据可视化

地图与图表**只用黑白 + opacity**：

- 陆地/省份填充：`#ffffff`，描边 `#000000` 1px
- 热力/权重：**用 opacity 阶梯**（0.08 / 0.2 / 0.4 / 0.7 / 1.0 的黑），不用色阶
- 有数据的点：实心黑
- 无数据的点：**空心**（白底黑边）——形状区分，不靠颜色

## 2. 字体

```css
--font-sans:  Inter, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif;
--font-mono:  ui-monospace, "SF Mono", Menlo, monospace;
```

**只有一种字族。** 上一版的宋体标题取消——参考站是单一无衬线体系，混入衬线会破坏那种「工程图纸」的统一感。

中文仍然走系统栈（苹方 / 微软雅黑），**不加载任何中文 web font**——几 MB 的字体在微信里等不起。Inter 只影响拉丁文与数字，可以走 web font（约 15KB 子集）。

### 字号阶梯

| 角色 | 桌面 | 移动 | line-height | 用途 |
|---|---|---|---|---|
| `display` | 56px | 32px | 1.05 | 首屏主标题 |
| `heading` | 40px | 26px | 1.11 | 区块大标题 |
| `subheading` | 24px | 20px | 1.2 | 学校名、当前视图 |
| `body-lg` | 18px | 16px | 1.4 | 首屏说明段落 |
| `body` | 16px | 15px | 1.5 | 正文、表格 |
| `caption` | 13px | 13px | 1.4 | 注释、口径、来源 |
| `label` | 11px | 11px | 1.2 | 全大写小标签，字距 `0.12em` |

字重只用 **400 / 500**。不用 600 以上——中文字体加粗会糊。
数字全部 `tabular-nums`。

## 3. 间距与形状

```
基本单位 4px
区块间距  桌面 80px（大区块 120px）· 移动 48px
卡片内距  20px
元素间距  20px
圆角      0px（全部：按钮、输入框、标签、卡片、图表容器）
阴影      无（浮层也不用，用 1px 实色黑边 + 白底）
```

**移动端区块间距压到 48px。** 桌面 120px 的呼吸感在手机上会变成「滚了半天什么都没有」。

## 4. 结构：hairline 是唯一的分区手段

| 规则 | 做法 |
|---|---|
| 分区 | 1px `border-ink/15`。**不用底色块、不用阴影、不用圆角卡片** |
| 区块开头 | 全宽 1px 实色黑横线 + 上方全大写小标签 |
| 表格 | 表头下 1px 实色黑；行间 `border-ink/12`；**无斑马纹** |
| 数字 | 右对齐 + `tabular-nums` |
| 选中态 | 反白（`bg-ink text-paper`） |
| 链接 / 按钮 | **裸文字 + `→`**。无背景、无边框、无内距。hover 加 1px 下划线 |

### 章节头写法

```
IVY MAP · 生源校研究
──────────────────────────────────────────────
剑桥大学的中国生源校
2023–2025 三届加权 · 按人均命中率排序
```

全大写小标签 → hairline → 大标题 → caption。**报刊的写法，不是 App 的写法。**

## 5. 建筑式背景字（参考站的签名手法）

首屏用一层**巨型描边字**做视觉骨架：

```css
.scaffold {
  font-size: clamp(180px, 34vw, 560px);
  line-height: 0.78;
  color: transparent;
  -webkit-text-stroke: 1px #000;
  opacity: 0.10;
  user-select: none;
  pointer-events: none;
}
```

内容用 `IVY` 或 `生源校`。**它永远不承载可读信息**，只做尺度和纵深。

约束：
- 只在首屏用一次，**不要每个区块都来一个**
- `aria-hidden="true"`，不进无障碍树
- 移动端缩到 `34vw`，且绝不能挤压正文
- opacity 不超过 0.12——它是骨架不是内容

## 6. 两条硬约束（不因换风格而变）

### 6.1 用户会截图发家长群

- 关键结论用**字重/字号**强调，不用颜色（现在本来也没颜色可用）
- 来源标注必须在截图范围内，**不能靠 hover**（移动端也没有 hover）
- 榜单的口径说明要紧跟表格，别放在很远的地方——截一半就丢了

### 6.2 家长年龄偏大

- 移动端正文与表格数字 **≥15px**
- 点击目标 **≥44×44**
- 术语首次出现给中文解释
- **不用纯英文标签**（全大写只用于 `IVY MAP` 这类品牌串和 `A-LEVEL` 这类专名）

## 7. 脚注式来源标注（保留）

上一版的机制保留，只是去掉颜色：

```
剑桥  33 人 ¹        实心上标 = L1 官方一手
领科   9 人 ⁽²⁾      加括号   = L2 权威二手
包玉刚 2 人 ⁽³⁾ˀ     括号加问号 = L3 推断/众包
                     ≈ 后缀   = 由 offer 折算而来
```

区块底部跟一个编号的「资料来源」列表。

论文引注的形式本身就在说「我说的话你可以去查」——这和产品的第一原则是同一件事，而且它在纯黑白系统里比彩色徽章更自然。

上标用 `text-ink/70`，hover 转 `text-ink` + 下划线。

---

## 8. 动效：只有两处

1. **滑杆重排的行位移** —— `transform`，180ms，`ease-out`
2. **首屏滑杆自动演示（US-1.0）** —— 约 2 秒，用户一交互立即中止

两处都必须尊重 `prefers-reduced-motion: reduce`。其余一律无动效；hover 用下划线，不用位移。

## 9. 明令禁止

| ❌ | |
|---|---|
| 任何彩色 | 系统只有 `#000` 和 `#fff`（`/v2` 的校色例外见 §1 的注与 [`design-system-v2.md`](design-system-v2.md)） |
| 任何圆角 | 全部 0px |
| 任何阴影 | 深度靠排版层叠，不靠高度 |
| 渐变、毛玻璃 | |
| 深色模式 | 参考站只有 light |
| emoji 装饰 | |
| 色阶热力图 | 用 opacity 阶梯 |
| 按钮 chrome（填充胶囊、圆角边框） | 裸文字 + `→` |
| 居中的正文段落 | 左对齐 + 限宽 |
| 骨架屏闪烁 | 静态占位 + 文字 |

## 10. 组件基调速查

| 组件 | 基调 |
|---|---|
| **首屏 hero** | 巨型描边背景字 + 48–56px 中文主标题 + 限宽说明段。上方全大写小标签 |
| **FeederTable** | 报刊表格。表头下 1px 实色黑，行间 hairline，无斑马纹，数字右对齐 tabular-nums，排名用 `text-ink/40` 小字 |
| **WeightSlider** | 一根 1px 黑轨 + 一个 12px 黑方块（**不是圆钮**）。两端全大写小标签 |
| **世界地图** | 纯白陆地 + 1px 黑描边（**无国界线**）。大学点：有数据实心黑、无数据空心 |
| **中国地图** | 纯白省份 + 1px 黑描边。城市热力用**黑色 opacity 阶梯** |
| **SourcePopover** | 白底 + 1px 实色黑边，无阴影无圆角。内容排版像参考文献条目 |
| **DeepCard** | 四段用全宽 hairline 分隔 + 全大写小标签，像报告章节 |
| **可行性闸门** | 折叠态一行字 + `填写 →` |
| **分享长图** | 最像纸的一屏。纯白底、巨型标题、报刊表格、底部资料来源与免责声明 |
