# IVY Map 设计系统 · 植物志式择校手册

> 本文是当前 UI 的实现约束。视觉方向不是“教育行业套模板”，而是一册安静、可信、
> 可以反复翻阅的择校手册：墨绿负责结构与信任，浅绿负责选择与引导，暖白负责长时间阅读。

## 1. 视觉原则

1. **沉稳，不沉闷。** 大面积暖白与浅绿降低压力，墨绿只落在标题、主动作与关键状态。
2. **像手册，不像后台。** 宋体标题提供编辑感，圆润控件与留白让数据工具保持亲和。
3. **颜色不替代事实。** 实心 / 空心、标签文字、来源与口径说明必须独立成立；绿色只帮助建立层级。
4. **圆角代表可触达。** 卡片、输入、按钮、选项与浮层使用统一圆角；分隔线、表格行与时间轴可以保持直线。
5. **卡片有边界，不堆卡片。** 只为可交互或需要独立比较的内容使用卡片，不做无意义的层层嵌套。

## 2. 色彩

色值定义在 `app/globals.css`，使用 OKLCH 保持明度变化一致。

| Token         | 角色         | 典型用途                      |
| ------------- | ------------ | ----------------------------- |
| `ink`         | 墨绿中性文字 | 正文、表格、图表文本          |
| `paper`       | 暖白画布     | 页面底色、截图底色            |
| `surface`     | 高层暖白     | 卡片、输入、浮层              |
| `forest`      | 主题墨绿     | 主按钮、选中态、关键数字      |
| `forest-deep` | 深墨绿       | 深色段落、页脚、重点入口      |
| `leaf`        | 叶绿         | 小标题、进度、focus、地图数据 |
| `sage`        | 浅叶绿       | 深底主动作、柔和强调          |
| `mint`        | 雾绿         | 选择背景、说明块、轻提示      |
| `cream`       | 暖米色       | 次级信息、图表底、辅助标签    |
| `line`        | 绿灰描边     | 卡片边界、表格与输入框        |

视觉权重大致遵循 60 / 30 / 10：暖白画布最多，浅色表面其次，墨绿与叶绿只用于重点。

### 对比与语义

- 正文在 `paper` / `surface` 上使用 `ink`，不使用浅灰正文。
- 墨绿底只配 `paper` / `sage`，不用灰色文字。
- warning / 缺数据不能只靠颜色，必须同时出现明确文字。
- 大学校色只做身份识别，不编码产品状态，边界见 `design-system-v2.md`。
- 暂不提供暗色模式；这套界面以分享截图和长文阅读为主要环境。

### 地图与图表

- 地图陆地用雾绿，边界用绿灰；有数据点使用墨绿 / 叶绿。
- 无数据继续用空心点，有数据用实心点，保证色弱与黑白打印仍可辨认。
- 热力同时使用叶绿色与 opacity 阶梯，不能只靠一个连续色阶传达状态。
- tooltip 使用 `surface`、`line` 与 12px 圆角。

## 3. 字体

```css
--font-sans: 'Avenir Next', Avenir, -apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif;
--font-display: 'Songti SC', STSong, 'Noto Serif CJK SC', 'Source Han Serif SC', serif;
--font-mono: ui-monospace, 'SF Mono', Menlo, monospace;
```

- `h1` / `h2` 使用本地宋体系，正文与 UI 使用无衬线系统栈。
- 不下载大型中文 web font，保证微信内打开速度与无布局跳动。
- 正文移动端不小于 15px；关键说明建议 16px。
- 数字、表格与时间序列使用 `tabular-nums`。
- 层级靠字号、字重、颜色与留白共同建立，不靠全部加粗。

## 4. 圆角、边界与深度

| 对象                     | 圆角     |
| ------------------------ | -------- |
| 小控件、输入             | 12–14px  |
| 说明块、筛选项           | 16–18px  |
| 内容卡片                 | 20–24px  |
| 首屏 / 大区块            | 28–30px  |
| 主动作、导航选中、短标签 | `9999px` |

- 卡片默认 `1px solid line`，不要使用厚彩边。
- 静态内容只使用极轻的 `shadow-sm`；可交互卡片 hover 才提升到 `shadow-card`。
- 阴影必须带墨绿色相，不用纯黑灰影。
- 表格行、章节分隔与时间轴是结构线，不强行加圆角。

## 5. 间距与布局

- 4px 基础网格：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 80。
- 核心页面最大宽度 `max-w-7xl`；长文最大阅读宽度约 65ch。
- 移动端左右 12–16px，桌面 24–32px。
- 区块之间 48–80px，相关内容内部 12–24px。
- 列表使用自适应网格；手机不是缩小桌面，而是重排成单列并保留完整功能。
- 避免卡片套卡片。辅助信息可用无边框 `mint` / `cream` 色块形成次级层级。

## 6. 组件语言

### 导航

- 桌面与移动端都使用圆角外壳；移动端链接换行，不隐藏关键入口。
- 当前页面用 `mint` 胶囊表示，主品牌使用墨绿圆形标记。
- 搜索输入始终有可见边界、44px 高度和明确 focus ring。

### 按钮与链接

- 主动作：墨绿实心胶囊；深色背景上的主动作使用 `sage`。
- 次动作：暖白底 + `line` 描边。
- 文内链接可以保持裸文字与箭头；不要把每个链接都做成按钮。
- hover 只做轻微上移或颜色变化，时长 180–300ms，不使用弹跳。

### 大学卡片

- 24px 圆角、暖白表面、轻描边；hover 轻微上移。
- 学校品牌色仅用于顶部细色带、校徽兜底与画像指纹。
- 风格摘要使用 `mint`，领域使用低权重 `cream` 标签，主详情动作使用墨绿。

### 数据与来源

- 关键事实旁保留来源入口，移动端不能依赖 hover 才能看到。
- 表格保持紧凑，不为追求“高级感”牺牲横向比较效率。
- 估算、编辑判断、官方数据必须有文字标签与形状区别。

## 7. 动效

- 只为状态变化、卡片 hover、时间轴进入与页面重点转场服务。
- 使用 `cubic-bezier(0.22, 1, 0.36, 1)` 等自然减速，不使用 bounce / elastic。
- 不动画宽高、padding 与 margin；使用 transform 与 opacity。
- 所有动效尊重 `prefers-reduced-motion: reduce`。

## 8. 无障碍与验收

- 点击目标至少 44×44px；focus ring 使用 `leaf`，不能被移除。
- 正文对比度至少 WCAG AA；placeholder 也必须可读。
- 390px 不得横向滚动，不得隐藏搜索、收藏、来源或下一步动作。
- 每轮 UI 变更至少检查：入口页、大学目录、大学详情、新手流程；桌面与 390px 各一次。
- 截图转灰度后，实心 / 空心、文字标签与来源仍应能够解释数据。

## 9. 禁止项

- 纯黑 / 纯白大面积界面
- 直角卡片、直角按钮、直角输入与直角浮层
- 紫蓝渐变、霓虹、玻璃拟态、发光边框
- 大量同尺寸“图标 + 标题 + 描述”的模板卡片
- 用颜色暗示大学好坏或个人录取概率
- 为装饰而添加无语义图表、sparkline 或渐变文字
