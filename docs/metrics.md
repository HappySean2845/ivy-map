# 指标口径定义：Feeder Score / CAI / Leverage

> 本文是 [`PRD.md`](../PRD.md) §7 的完整展开。§9 示例计算里的 A 校 / B 校数字均为**格式示意**，非真实数据；**唯一的例外是 §3.1 的两组实测 `k` 值**，它们是真实战报数字（但来源尚待核实，见该节的提示）。
>
> **本文属于产品文档，不是技术文档。** 口径是产品决策——「人均密度缺分母时显示什么」直接决定用户看到的排序，因此归产品定义。至于用什么语言实现、算完存哪、要不要缓存，属于 Design Doc。

---

## 0. 为什么不能直接按 offer 数排序

国内国际化学校的「升学战报」几乎全部以 **offer 数**发布。直接拿它排序有三个致命问题：

1. **一人多 offer**。头部学校学生人均 4–8 枚 offer 很常见（实测值见 §3.1），「30 枚藤校 offer」可能只对应 6–8 个人头。**注意这一条只对美国方向成立**——英国走 UCAS，一人一份申请，「枚」就是「人」（§3.1 末）。
2. **分母被隐藏**。毕业生 600 人的学校拿 20 枚，和毕业生 90 人的学校拿 8 枚，哪个对**你家孩子**更有利？前者是 3.3%，后者是 8.9%。
3. **年份混算**。三年前的成绩不代表今天的教学团队和招生政策。

Feeder Score 的全部工作，就是修正这三点。

---

## 1. 符号定义

| 符号 | 含义 |
|---|---|
| `S` | 国内高中（School） |
| `U` | 目标大学（University） |
| `T` | 赛道（Track）：**AP / IB / A-Level 三选一**，无「其他」 |
| `y` | 毕业年份 |
| `Admits(S,U,T,y)` | 学校 S 在 y 届、T 赛道被大学 U 录取的**去重人数** |
| `Offers(S,U,T,y)` | 同上，但为 offer 口径 |
| `Grads(S,T,y)` | 学校 S 在 y 届、T 赛道的毕业生总数（密度的分母） |

---

## 2. 时间权重

近的一届更能代表当下，但样本量太小会抖动，所以取三届加权而非只看最近一届。

```
w(y) = 0.5   最近一届
       0.3   前一届
       0.2   再前一届
```

三届之和为 1，方便解释：「加权后的等效年录取人数」。

---

## 3. Offer → 人数折算

当某条记录只有 offer 口径时：

```
k(S,y) = total_offers(S,y) / graduates_count(S,y)     # 该校当年人均 offer 数
Admits_est = Offers / k(S,y)
```

**规则**
- `k` 取值裁剪到 `[1.0, 10.0]`，防止异常数据放大误差。
- 若该校当年缺 `total_offers` 或 `graduates_count`，退回全局中位数 `k̄`（MVP 阶段取 **4.5**，随数据量迭代）。
- 任何经过折算的记录，`confidence` **强制下调一级**（L1→L2，L2→L3），UI 显示「估算」标记。
- 若同一 `(S,U,T,y)` 同时存在人数口径与 offer 口径，**永远优先采用人数口径**。

> 折算是必要的妥协，但绝不能是隐形的。凡是折算过的数字，界面上必须看得出来。

### 3.1 兜底值为什么从 4.0 上调到 4.5

原来的 4.0 是拍脑袋定的行业观感值。实际去战报里算了两所，**实测普遍比 4.0 高**：

| 学校 | 届 | 毕业生 | 公布的录取/offer 总数 | 实测 `k` |
|---|---|---|---|---|
| 深圳国际交流书院（深国交） | 2025 | 约 450 | 2000+ | **≈ 4.4** |
| 上海七宝德怀特高级中学 | 2025 | 170 | 939 | **≈ 5.5** |

> ⚠️ **这两组数字来源待核实**：目前来自战报的公开转述，尚未逐条回溯到学校官方发布页。入库前必须按 [`data-sources.md`](data-sources.md) §3.3 补上来源链接，否则不得作为 L1 使用。

**兜底值取 4.5**，落在两个实测点之间、略高于中位观感。这个值只在「该校当年既没有 `total_offers` 也没有 `graduates_count`」时才生效——**它是最后一道兜底，不是常用路径**。能算出该校自己的 `k` 就一定用该校自己的。

**为什么宁可取高一点**：`k` 偏低会把 offer 数**高估**成人头（除数小 → 商大），也就是把学校的成绩往大了报——这正是产品要修正的失真。取高一点是保守方向的错误，符合原则 §5.1「宁可标数据不足」的取向。

> **英国方向不走这条路。** UCAS 一人一份申请、最多 5 个志愿且牛剑二选一，所以「剑桥 4 枚」就是 4 个人头，`basis` 直接记 `admits`，不需要折算、不需要降置信。Demo 主线选剑桥的第二个理由就是这个（[`PRD.md`](../PRD.md) §1.4）。

## 4. 规模强度 Volume

```
Volume(S,U,T) = Σ_y w(y) · Admits(S,U,T,y)
```

回答：**「哪所学校往这所大学送的人最多？」**

对应的用户诉求：校友网络、备考氛围、招生官对学校的熟悉度、同侪水平。

---

## 5. 人均密度 Density

```
                Σ_y w(y) · Admits(S,U,T,y)
Density(S,U,T) = ───────────────────────────
                Σ_y w(y) · Grads(S,T,y)
```

回答：**「我家孩子在这所学校，命中这所大学的历史比例是多少？」**

> **分母的坑（去掉「其他」赛道后更容易踩）**：`Grads(S,T,y)` 是**该赛道**的毕业生数，不是全校毕业生总数。有些学校同时开 IB 和 OSSD/日本课程——算 IB 密度时若图省事用了全校总数，分母被其他赛道撑大，密度会**系统性偏低**，滑杆的排名反转就出不来了。本次不收录其他体系的赛道数据，但那些学生仍然存在于全校总数里。

> **比缺分母更麻烦的是「分子拆不到赛道」**：战报极少标注赛道，多赛道学校（如同时开 IB 和 AP 的学校）报的「剑桥 4」不知道该记在哪个赛道上。分子归不了赛道，按赛道算的分母就没有意义。**纯单赛道学校（纯 A-Level 的深国交、光华剑桥、领科等）不存在这个问题**，这也是主线选 A-Level 的原因。录入规则见 [`data-sources.md`](data-sources.md) §3.5。

**缺分母的处理**：若 `Grads` 缺失，`Density` 记为 `null`，UI 显示 `—`。
- 排序时置于同 Volume 档位的末尾，并标注「分母缺失」。
- **绝不用 0 代替 null**，也绝不估算分母。分母是这个算法的地基，猜分母等于伪造结论。

## 6. Feeder Score 与「规模 ↔ 概率」滑杆

两个维度量纲不同，先各自在**当前筛选结果集内**做 min-max 归一化到 `[0,1]`：

```
norm(x) = (x - min) / (max - min + ε)          ε = 1e-9
```

合成（几何平均形式，避免单维极值通吃）：

```
Score(S,U,T | α) = norm(Volume)^α · norm(Density)^(1-α)
```

- `α = 1.0` → 纯规模排序（滑杆最左）
- `α = 0.5` → 默认平衡
- `α = 0.0` → 纯密度排序（滑杆最右）

**为什么用几何平均而不是加权求和**：求和允许一个维度用极值补偿另一个维度的零分（一所巨型学校即使人均密度接近 0 也能靠体量排第一）。几何平均下任一维度趋零则总分趋零——这更符合家长的真实判断：一所人均命中率极低的大校，不该出现在榜首。

**归一化在结果集内做，不是全局做**。用户筛「上海 + IB」时，排序应当反映这 6 所学校之间的相对关系，而不是它们在全国 200 所学校中的绝对位置。

### 6.1 滑杆的动态解读文案

拖动时对比新旧 Top 1，自动生成一句话。模板：

```
你正在按{规模|概率}优先排序。第 1 名从「{A}」换成了「{B}」——
后者近三年送进{U}的人数是前者的 {x}%，但毕业生规模只有 {y}%。
```

若 Top 1 未变化：

```
无论按规模还是概率，「{A}」都排在第 1 —— 这类学校很少见。
```

## 7. 择校杠杆率 Leverage

**这是本产品最反直觉、也最建立可信度的指标。**

对大学 `U`，先算每所生源校的份额：

```
share(S,U) = Volume(S,U,*) / Σ_S' Volume(S',U,*)
```

再取赫芬达尔指数（HHI）：

```
Leverage(U) = Σ_S share(S,U)²
```

| HHI | 等级 | 含义 | 文案方向 |
|---|---|---|---|
| > 0.15 | **高** | 录取高度集中在少数几所高中 | 「进对高中的影响，可能大于多刷两分标化」 |
| 0.05–0.15 | **中** | 有明显头部但也有长尾 | 「择校有帮助，但不是决定性的」 |
| < 0.05 | **低** | 分散在上百所高中 | 「这所大学不太看你从哪来，钱和精力建议花在别处」 |

> **为什么要主动告诉用户「不必折腾」**：一个只会说「快来择校」的产品是营销物料；一个会说「这件事对你不重要」的产品才是决策工具。**Leverage 低的提示，是全站可信度最高的一句话。**

**统计有效性护栏**：`Leverage` 仅在该大学的样本高中数 ≥ 10 且加权录取总量 ≥ 15 时展示，否则显示「样本不足」。样本太小时 HHI 天然偏高，会给出误导性的「高杠杆」结论。

## 8. 中国友好度 CAI（China Access Index）

五个维度，各 0–2 分，合计 0–10，映射到 A–E。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| **录取体量** | 近三年大陆加权录取 < 5 | 5–20 | > 20 |
| **趋势** | 三年下滑 | 持平 | 上升 |
| **来源广度** | 生源校 < 10 所 | 10–40 所 | > 40 所 |
| **在华投入** | 无中国区招生代表/活动 | 有区域招生官或宣讲 | 有常设中国办公室/项目 |
| **国际生资助** | 不提供 | need-aware | need-blind 或全额可申请 |

```
A: 9–10   B: 7–8   C: 5–6   D: 3–4   E: 0–2
```

**展示规则**：等级必须可展开看到五个维度各自的得分与依据来源。只给字母不给构成，等于让用户盲信——违反产品原则 §5.1。

## 9. 完整示例计算（数字为示意）

目标：剑桥大学 · 上海 · IB 赛道。候选两所学校。

### 原始数据

| 学校 | 年份 | 录取人数 | 该赛道毕业生 | 口径 |
|---|---|---|---|---|
| A 校 | 2025 | 6 | 180 | admits |
| A 校 | 2024 | 5 | 175 | admits |
| A 校 | 2023 | 4 | 170 | admits |
| B 校 | 2025 | 3 | 48 | admits |
| B 校 | 2024 | 2 | 45 | admits |
| B 校 | 2023 | 3 | 44 | admits |

### Volume

```
A: 0.5×6 + 0.3×5 + 0.2×4 = 3.0 + 1.5 + 0.8 = 5.30
B: 0.5×3 + 0.3×2 + 0.2×3 = 1.5 + 0.6 + 0.6 = 2.70
```

### Density

```
A 分母: 0.5×180 + 0.3×175 + 0.2×170 = 90 + 52.5 + 34 = 176.5
A 密度: 5.30 / 176.5 = 3.00%

B 分母: 0.5×48 + 0.3×45 + 0.2×44 = 24 + 13.5 + 8.8 = 46.3
B 密度: 2.70 / 46.3  = 5.83%
```

### 归一化（结果集内只有两所，故为 0 和 1）

```
norm_Volume:  A = 1.0, B = 0.0
norm_Density: A = 0.0, B = 1.0
```

> 两所学校时归一化退化为 0/1，示例仅用于说明流程。实际结果集通常 5–15 所，归一化才有意义。

### Score

| α | A 校 | B 校 | 榜首 |
|---|---|---|---|
| 1.0（纯规模） | 1.00 | 0.00 | **A** |
| 0.5（默认） | 0.00 | 0.00 | 并列（退化，见下） |
| 0.0（纯概率） | 0.00 | 1.00 | **B** |

**这个退化暴露了一个真实问题**：两所学校时几何平均恒为 0。工程实现上需加平滑：

```
norm'(x) = 0.05 + 0.95 · norm(x)        # 下界抬到 0.05，避免零吞噬
```

平滑后：

| α | A 校 | B 校 | 榜首 |
|---|---|---|---|
| 1.0 | 1.000 | 0.050 | **A** |
| 0.5 | 0.224 | 0.224 | 并列 |
| 0.0 | 0.050 | 1.000 | **B** |

α=0.5 时并列是**正确结果**——在只有两所、且各占一个极端的情况下，本来就无法分出高下。UI 此时应并列展示并提示「这两所各有优势，建议看深度卡片对比」，而不是强行分个先后。

### 演示台词

> 「A 校三年送了 15 个孩子进剑桥，B 校只送了 8 个。按战报，A 校完胜。
> 但 A 校每届 180 个 IB 毕业生，B 校只有 48 个。
> 换算成人均——A 校 3.0%，B 校 5.8%。**B 校几乎是 A 校的两倍。**
> 家长真正该问的不是『哪所学校送得多』，而是『我家孩子在哪所学校机会更大』。这个滑杆，就是这两个问题的切换开关。」

## 10. 交接给 Design Doc 的问题

以下几点本文只给出**产品期望**，具体实现方式由 Design Doc 决定：

| 问题 | 产品期望 | 备注 |
|---|---|---|
| 归一化的下界平滑 | §6 的 `0.05` 下界是为了避免零吞噬，具体取值可调 | 调整会改变排序，**改之前先确认 Demo 主线的排名反转还在** |
| `k` 的全局中位数 | MVP 取 **4.5**（实测依据见 §3.1），随数据量迭代 | 应可配置，不要写死在多处。**改这个值会改变所有 offer 口径记录的排序**，改完先确认主线的排名反转还在 |
| 滑杆参数的可分享性 | 滑杆位置必须能被分享链接还原（US-8.2） | 传递方式由工程决定 |
| 计算时机 | 用户感知上必须「即时」（US-1.3、US-1.4） | 是否预计算、是否缓存，由工程按数据量决定 |

**唯一的硬性约束**：口径规则（§3 的折算与降级、§5 的 null 处理、§7 的样本护栏）不得在实现中被简化掉。这些不是优化项，它们是产品对用户的承诺。
