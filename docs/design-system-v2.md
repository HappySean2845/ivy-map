# 设计系统 v2 · 大学身份与数据画像

> 适用于 `components/v2/*` 与大学画像相关路由。主视觉规范以
> [`design-system.md`](design-system.md) 为准；本文只记录大学品牌色与画像组件的额外约束。

## 1. 大学校色只做身份识别

大学卡片需要快速识别学校，所以允许保留各校自己的品牌色，但它不能表达产品状态、好坏或推荐程度。

允许的位置：

1. 卡片顶部 3–5px 识别色带
2. 校徽缺失时的 monogram 背景
3. 画像指纹的填充、描边与顶点
4. 刷卡收藏时的瞬时反馈

正文、产品按钮、链接、focus ring、边框、标签与状态提示统一使用 IVY Map 的墨绿体系。
品牌色缺失时由 `brandOf()` 回退到主题墨绿；品牌色底上的文字必须走 `readableInkOn()`。

## 2. UniversityCard

- 14px 圆角、`surface` 背景、`line` 描边与极轻阴影。
- hover 只上移 4px，并切换为叶绿描边与 `shadow-card`。
- 风格摘要放在暖石灰 `cream` 区域并标注“编辑印象”。
- 知名领域可以使用 `cream` 小标签；它们不是专业排名。
- 主要招生事实使用墨绿数字，时间与口径作为较弱文字跟随。
- 画像指纹置于独立暖白区域，避免与正文挤在一起。
- 主详情动作是墨绿小圆角按钮，官网保持次级文字链接。

## 3. ProfileFingerprint

画像指纹描述差异，不计算总分：

- `kind: measured`：实心顶点，表示可追溯数据。
- `kind: editorial`：空心顶点，表示编辑评估。
- `level: null`：不补最低档，该轴用虚线表示缺失。
- 四根轴统一为“越外表示该特征越多”，不表示学校更好。
- 卡片只显示短标签与 1–5 档；详情页必须逐轴展示依据、性质与来源。

## 4. 数据性质必须可辨

- 风格简述固定标注为编辑撰写。
- 知名领域固定说明不是任何排名的名次。
- 录取率和录取人数不能混成一条趋势；分母缺失时不反推比例。
- 课程归因的“已证实 / 方向性 / 可能涉及”必须保留文字，不只换颜色。
- 未复核字段继续在详情页底部明确说明。

## 5. 截图与移动端

- 信息完整性不能依赖校色或 hover。
- 390px 下卡片保持单列、按钮 44px 高、画像与关键数字可读。
- 分享截图转成灰度后，实心 / 空心、标题、口径与来源仍然能独立成立。
