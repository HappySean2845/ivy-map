## 0. 为什么要偏离「没有第三个颜色」

主文档 §1 写着「没有第三个颜色」，§9 把「任何彩色」列为明令禁止。**这条偏离是有意的，理由要说清楚，否则下一个人照旧文档看会直接否决它。**

v2 的核心界面是**一张一张刷的大学卡片**。在这个形态下纯黑白有一个具体的失败：

> 刷到第 12 张时，用户已经分不清刚才那张是哪所学校了。

榜单里学校是表格的一行，有位次、有城市、有数字做锚点。卡片里没有这些——**卡片需要一个瞬时的识别锚点，而校色恰好是每所大学自己已经建立好的那个锚点。** 哈佛红和耶鲁蓝不是我们发明的装饰，是这些学校用了上百年的身份标识。

所以偏离的边界是：**校色只做身份识别，绝不做信息编码。**

## 1. 校色允许出现的四个位置

| # | 位置 | 实现 |
|---|---|---|
| 1 | 卡片顶部色带 | `h-[3px]`，`background: brand` |
| 2 | logo 缺失时的 monogram 方块底 | `background: brand`，前景色走 `readableInkOn()` |
| 3 | 雷达图填充与描边 | 填充 `withAlpha(brand, 0.12)`，描边纯校色 1.5px |
| 4 | 右划「收藏」的瞬时反馈 | 提示块底色。左划「跳过」用 `var(--ink)`，**不是**校色 |

**这个列表是封闭的。** 需要第五个位置时先改本文，不要在组件里就地扩张。

## 2. 校色绝不出现的位置

正文、标题、边框、hairline、表格、数字、按钮、链接、focus 环、任何状态提示（成功/警告/缺数据）。

层级仍然靠 opacity（`text-ink/60`、`/40`、`border-ink/15`），选中态仍然是反白（`bg-ink text-paper`）。

## 3. 两条硬约束

**校色缺失时整块退回纯黑白。** `brandColor: null` 不是错误状态，卡片照样成立——`lib/v2/brand.ts` 的 `brandOf()` 兜底成 `#000000`。

**信息完整性不依赖校色。** 主用户会截图发家长群，微信压缩后校色会失真甚至偏色。所以任何一张 v2 页面在纯黑白下必须信息完整。自测方法：截图后转灰度，看是否还能读懂。

## 4. 对比度：`readableInkOn()`

校色深浅跨度极大——普林斯顿橙 `#E77500` 和耶鲁蓝 `#00356B` 上面写白字，一个看不见、一个正好。所以任何在校色底上放文字的地方**必须**走 `lib/v2/brand.ts` 的 `readableInkOn(hex)`，不要手写 `text-white`。

阈值用 WCAG 的 0.179 相对亮度（黑字与白字对比度相等的那个点），不是拍一个 0.5。

## 5. 新增组件规范

### 卡片（`UniversityCard`）

**白底 + 1px 实色黑边，不是圆角阴影卡。** 圆角仍然是 0，阴影仍然没有。卡片的「卡片感」由边框和顶部色带承担，不由 elevation 承担。

两个变体：
- `deck` 刷卡用，信息最全，固定高度（`h-[540px]`），简述 `line-clamp-4`
- `grid` 网格用，压缩到可扫密度，雷达图去掉轴标签，简述 `line-clamp-3`

### 雷达图（`ScoreRadar`）

**手写 SVG，不用 ECharts。** 理由在组件注释里，核心是 ECharts radar 表达不了下面这三种状态：

| 状态 | 画法 |
|---|---|
| `kind: 'measured'` | 顶点**实心**（校色填充），可点开看来源 |
| `kind: 'editorial'` | 顶点**空心**（白底校色描边） |
| `value: null` | 该顶点**不画**，多边形跳过它，该轴画**虚线** |

这是主文档 §1「有数据实心 / 无数据空心」形状语言的直接延续。

**轴向必须写在图外。** 「录取难度」越外越难——顶到最外圈的意思是「你大概进不去」，不是优点。所以：
- 图旁必须列出 `PROFILE_DIM_DIRECTION` 的四条方向说明
- 图下必须写「不能按面积大小读」
- **不做任何「面积越大越好」的暗示**

### 刷卡（`SwipeDeck`）

- 不引动画库。pointer events + CSS transform，覆盖触屏与鼠标
- 划出阈值：位移 > `min(视口宽, 640) × 25%`，或速度 > 0.5px/ms 且位移 > 40px
- **键盘 `←` / `→` 必须能划**，且输入框聚焦时让位给光标移动
- 屏幕上必须同时有「跳过 / 收藏」两个按钮——它们不是装饰，是桌面端和无障碍的主路径，也是手势的说明书
- `prefers-reduced-motion: reduce` → 直接换卡，无位移动画
- 只渲染当前 + 下一张

### 强调（`Emphasis`）

术语教学的文案里 `**粗体**` 是内容的一部分（指出哪句最容易被误解）。用 `<strong className="font-medium">`——字重 500，不用 700，主文档 §2：中文加粗到 600 以上会糊。

## 6. 数据性质必须在界面上可辨

这是 v2 最重要的一条，比任何视觉规范都重要。

四维评分里有三维目前是**编辑评估**，不是官方数据。雷达图天生看起来像"客观测量"，所以：

- 卡片上：实心 / 空心顶点
- 详情页：每根轴列出 `basis`（怎么算的）、性质标签（官方数据 / 编辑评估）、以及 measured 的来源弹层
- 风格简述下方固定标注「编辑撰写」
- 知名领域下方固定标注「不是任何排名的名次」
- `reviewed: false` 的画像，详情页底部明示哪些字段未复核

构建期门禁（`scripts/build-data.ts`，日志前缀 `[v2 profiles]`）：**声称 `kind: 'measured'` 但没有 `sourceIds` 直接构建失败。**
